# Здесь будет фуллстак приложение простой социальной сети с использованием typescript, nest.js, react.js, postgreSQL  

---

## Как запустить приложение

### 1. Скачивание зависимостей 
установка происходит в каждой директории отдельно командой:
```bash
  npm i
```

### 2. Настройте .env файл по примеру из .env.example


### 3. Запуск backend части:
```bash
  cd backend

  npm run start:dev
```

### 4. Запуск frontend части:
```bash
  cd frontend

  npm run start
```

---

## Подключение к базе данных

Так как я использую ORM prisma, приходится в ручную синхронизировать бд с бд в psql, поэтому требуется вводить следующие команды:
```bash
  npx prisma migrate dev --name <имя_миграции>

  npx prisma db push
 ```
